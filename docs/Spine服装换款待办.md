# Spine 服装换款待办

目标是在 ModStudio 里把一种服装换成另一种。首个案例用 `char003793` 的裙摆换成长裤，生成新贴图、网格和可播放原动作的新皮肤。默认由工具生成初稿，用户确认款式、分件和动作效果。

## 可复用的基础

- [x] 已用 `char003793` 验证角色图重绘、UV 回写、原尺寸 UV 补绘和动画对比。见 [贴图重绘流程](char003793-Spine贴图重绘流程.html)。
- [x] 已验证按图集像素计算 `idle` 与 `motion` 的可回写范围。见 [多帧覆盖分析](char003793-Spine动画多帧覆盖分析.html)。
- [x] 已确认 `Calf_l`、`Thigh_r` 和 `Calf_r` 是带骨骼权重的 Mesh，可给新裤腿提供初始权重。

## 1. 选择旧服装并生成款式

- [ ] 在角色预览里提供「换款并新建附件」入口。用户选中原裙摆和新服装款式，可附参考图。
- [ ] 自动准备绑定姿势的整身参考、原服装选区和关节位置，生成候选换装图。提示词约束角色姿势和比例，让腰线、膝盖和裤脚能用于后续定位。
- [ ] 用户选定一张款式稿。预览中对不齐的位置允许调整，确认后再拆分。

## 2. 拆分并补全新服装

- [ ] 从款式稿提取新服装，按动作拆出腰头、左裤腿和右裤腿。每块输出透明 RGBA 图片、裁切矩形与在绑定姿势中的位置。
- [ ] 自动补绘被手或玩偶挡住的布料。使用单独的组装效果图提供风格参考，在各块的新 UV 裁切图上补全缺口。
- [ ] 显示原角色和新部件的叠加预览。用户仅在分错左右、边缘串色或遮挡区补错时修正遮罩。

## 3. 生成网格与 UV，复用腿部权重

- [ ] 实现「新轮廓超出旧网格三角形」时的网格重建：从重绘结果的 Alpha 轮廓重新提取边界并三角化，生成能覆盖新轮廓的网格与 UV；旧网格范围内优先按原三角形重心映射到骨架空间，超出旧网格的新增顶点参考 [OpenBone 的轮廓追踪与 UV 仿射放置](https://github.com/UXCentury/open-bone/blob/main/packages/core/src/trace.ts) 做外推对照。随后为新增顶点继承或估算骨骼权重，并处理旧网格的变形键/关联网格，再用原动画检查轮廓覆盖和变形质量。
- [ ] 从每块的 Alpha 轮廓生成外边界和三角网格，在腰部、膝盖附近增加可用于弯曲的控制点。
- [ ] 从网格顶点在新裁切图中的位置计算归一化 UV，记录贴图区域、网格、部件与槽位的对应关系。
- [ ] 在绑定姿势下，把新裤腿的顶点按左右腿分别匹配到原腿部网格，用对应三角形内插值得到初始骨骼权重，归一化后预览。
- [ ] 用户可在对齐预览中校正腰线、膝盖或裤脚。出现局部拉扯时，再局部调整权重。

## 4. 创建新皮肤并导出

- [ ] 创建新服装的附件与皮肤配置，安排腰头、裤腿、手和玩偶的绘制顺序，为新皮肤处理原裙摆槽位的显隐。
- [ ] 打包新裁片，输出 Spine 数据、图集和 PNG。导出前检查当前 Spine 版本、附件引用、轨道中的显隐与裁剪关系。
- [ ] 添加在原皮肤与新皮肤之间切换的预览，以及新皮肤的保存入口。

## 5. 用原动画验收

- [ ] 自动播放完整的 `idle` 和 `motion`，提供原皮肤与新皮肤的同步对比，并记录需要复查的帧。
- [ ] 检查左右裤腿随各自的腿移动，膝盖弯曲时边缘平顺，腰头接缝没有裂隙，手和玩偶的遮挡正确。
- [ ] 用户确认动作效果。有异常时跳到对应帧，调整部件边缘、控制点、权重或绘制顺序后重播。
- [ ] 导出后重新打开生成的 Spine 资产，确认两段动画可播放，所有新附件都能找到对应图集区域。

# Spine 贴图重绘

先确认目标是**复现存档**、**重新生成**还是**改变服装结构**。从用户给的路径读取骨骼、图集、贴图、目标部件和已有遮罩。保留原资源，输出新图集与可复查的映射记录。

## 复现 char003793 存档

使用仓库根目录的 Node.js 和项目依赖 `pngjs`。原素材目录应包含 `char003793.png` 和 `char003793-skirt-mask.png`。目录可由用户指定。

```powershell
node .\skills\spine-texture-repaint\scripts\replay-char003793.cjs 'F:\Neowiz\modder\test\原版内容 - 角色立绘 - char003793' '.\char003793-replay'
```

脚本从流程 HTML 提取两次真实生成的输入、提示词和输出，用存档取样索引重算两轮图集并逐通道核对最终结果。动画坐标和取样判定沿用存档。复现时预期计数是第一轮 **33,995**、第二轮 **8,885**（直接 **8,317**，同裙片邻近 **568**）、剩余 **25**，覆盖 **42,880 / 42,905**。打开 HTML 的第 3 页核对两侧坐标，第 4 页播放完整 4 秒 `idle`。

## 对同结构贴图重新执行

按 [实现说明](references/reproduction.md) 执行以下顺序。

1. **准备输入。** 加载与素材版本兼容的 Spine Runtime，记录动画、时间、Skin、图集页和目标附件。将目标网格的 UV 足迹、用户选区和原图有效 Alpha 相交，记录可写像素与附件归属。
2. **重绘组装图。** 冻结一个姿势，将目标附件按绘制顺序渲染到独立画布。保存原始工作图、工作图坐标变换及每块裙片的工作图三角形与图集 UV 三角形。把组装图送给图像编辑工具，要求保持裁切、轮廓、开口和褶皱的位置。保存原始输出与实际提示词。
3. **回写第一轮。** 从候选图集像素中心出发，用三角形的重心坐标投影到原工作图，再按输出尺寸换算并取色。只有正确可见附件和通过取样检查的 RGB 才写入。记录逐像素写入掩码，供下一轮求缺口用。
4. **补绘原尺寸 UV。** 从第一轮图集裁出目标部件，以原像素尺寸排进独立画布，记录原图集与工作图矩形。向图像模型分别提供 **UV 工作图、第一轮生成的组装图、对齐工作图的黑白缺口图**。把模型输出对齐回工作图，用平移坐标切回，只写缺口内通过校验的 RGB。原始 Alpha 从图集保留，邻近补齐限于同一附件的有效布料。
5. **验收并输出。** 核对两轮互斥、选区外像素和原 Alpha，逐区报告直接写回、邻近写回与剩余。用产出的图集渲染原动画，拖动对比线检查接缝、层叠和显露出的缺口。保留可回溯的输入、输出、遮罩、图集和统计。

用户要求真实生成且当前环境有适用的图像编辑工具时，用真实参考图执行两轮。若工具缺少独立参考输入或生成结果无法对齐，报告该轮的状态。复现存档时直接使用内嵌输出。新生成结果按当前贴图的几何与像素验证验收，案例计数仅用于核对存档。

## 服装结构变化

颜色、花纹或相近材质变化可沿用原网格。裙摆换成裤装、轮廓跨度明显变化或新服装有新的前后遮挡关系时，先确定新服装的分件、轮廓、遮挡和活动区域，再建附件、网格、UV 与权重并复查动画。可以用生成图作为设计或纹理参考。详见仓库 `docs/Spine服装换款待办.md`。
